# 站存-发车流程填表桥（Chrome 扩展）

让「股道存车计算器」页面与「发车作业报表」页面在**同一浏览器的两个标签页**之间传数据，
**跨域可用**（不受同源策略限制），不需要改报表网站。

## 一、安装（一次性）

1. 把本目录 `dep-bridge-extension` 放到一个固定位置（不要放桌面临时文件夹）。
2. 打开 `chrome://extensions/`，右上角打开 **开发者模式**。
3. 点 **加载已解压的扩展程序** → 选择 `dep-bridge-extension` 目录。
4. 若主页面是**双击 `HTML/index.html`（file://）**打开的：
   在扩展卡片点「详细信息」→ 勾选 **允许访问文件网址**。
5. 修改 `background.js` 顶部两行，改成你的真实报表地址：

```js
var REPORT_URL   = 'http://10.190.136.28:6060/WebReport/ReportServer?op=fs_main&cmd=entry_report&id=2932';
var REPORT_MATCH = '10.190.136.28';        // 判断「哪个标签页是报表页」的网址特征
```

改完后回到 `chrome://extensions/` 点扩展卡片上的 **刷新** 按钮。

## 二、使用

1. 打开报表标签页（也可以不打开，扩展会自动开一个）。
2. 在计算器页面点主表的「编好」→ 报表页的 股道 / 辆数 / 换长 / 尾车车号 自动填入。
3. 输入车次后 **回车或点别处** → 车次填入报表页（逐字输入不刷新、不发消息）。
4. 报表页打开时，「编组车次」列会回传给计算器页，输入重复车次会显示红色三角警示标。

## 三、文件说明

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单；content script 注入所有页面（含 file://） |
| `background.js` | 路由：计算器页 ↔ 报表页；报表页未开时自动新建 |
| `content.js` | 页面 ↔ 扩展 的消息桥（ISOLATED world） |
| `page-fill.js` | 真正写单元格的脚本（MAIN world，能访问帆软 `contentPane`） |

## 四、常见问题

- **填了没反应**：F12 看控制台；确认扩展已启用、报表页已加载完；帆软页面为异步渲染，
  扩展内置了 2s / 4s / 7s 补发，仍不生效就刷新报表页再点一次「编好」。
- **单元格写错位置**：真实报表的模板行号若不是第 4 行，改 `page-fill.js` 里的 `CELLS`。
- **想只作用于报表页**：把 `manifest.json` 里 `page-fill.js` 那段的 `matches`
  从 `<all_urls>` 改成你的报表地址，如 `"http://10.190.136.28:6060/*"`。
- **重复打开多个报表标签页**：`background.js` 只在「一个匹配 `REPORT_MATCH` 的标签页都没有」时才新建。
  若仍重复开，说明 `REPORT_MATCH` 与实际报表网址不一致，两个常量要一起改。
- **帆软平台页（op=fs_main）填不进去**：平台页常把报表放在内部 iframe，本扩展已用
  `all_frames: true` 注入所有 frame，正常可覆盖；若仍失败，F12 看报表内容在哪个 frame，
  把 `page-fill.js` 的 `matches` 精确写成该 frame 的地址。
