使用方法：顶部「车号 / 内容」切换模式，输入框实时搜索（无需回车）；多关键词空格分隔，任一命中即列出。
车号模式：只匹配车号；右侧「开头 / 包含」切换匹配方式（默认包含）。输入完整车号且全站唯一命中时，自动展开该车所在整条股道并定位到该行，便于查看其前后邻车。
内容模式：匹配 车种 / 到站(处理后) / 品名 / 记事 / 收货人 / 车次 任一字段。
结果操作：点击某行 → 打开该股道明细并高亮定位这辆车（搜索抽屉保留在后方，关掉明细即回到结果）；点「清空」重置条件。
