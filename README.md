# 站存计算器

铁路车站「股道存车」计算与展示工具，提供 **VBA 版**（Excel 宏工作簿）与 **纯前端 HTML 网页版**（含铁路地图模块）两套实现。

## 在线访问

网页版已部署到 GitHub Pages，点击即可直接使用：

👉 **https://momdax.github.io/zhancun-calculator/index.html**

（打开后为股道存车计算器，首次需点击「功能 → 设置」选择数据文件夹或通过文件下拉框加载 xls 现车数据。）

## 功能特性

- **股道存车总览**：按股道展示车数、换长、载重、空/重车、方向、到站、车种、老牌车、到达车次及注意事项。
- **注意事项筛选**：自动从记事列提取「暂不走 / 去向不明 / 点后开 / 列扣 / 检无计划 / 坏 / 超偏 / 未洗 / 禁止 / 有磨损」等简要提示（词级筛选，对齐 VBA 显示逻辑）。
- **不常用股道开关**：工具栏「隐藏非常用股道」可一键隐藏 X 线、YX1、YQX、ZXX、DY、TSY、YH、临时等不常用股道（默认隐藏）。
- **站存计算（31814）**：弹出统计面板，按方向/车种/品名等多维度汇总。
- **待装股道大组（作业区）**：31814 面板左侧按「作业区」分组展示股道——
  - 货场作业区（货场）、勒沟作业区（中粮 / 大洋 / 港务局）、鹰岭作业区（永鑫 / 天煤 / 石化 / 国投 / 超智 / 广明 / 天油）、中油作业区（中油）。
  - 单组大组（货场、中油）隐藏子组按钮，计数移到段标题后；**点击段标题可整段全选 / 清空全选**（多组大组同样支持）。
- **待卸纠正**：31814 面板底部提供 `C X P G` 输入框与「待卸校对」按钮，对应 VBA「待卸纠正」。自动算出的待卸与实况有偏差时，填入正确车数点「待卸校对」即可：待卸取输入值，空车按相反偏差增减（待卸多了放到空车 / 少了从空车取，G 对应分母路罐），二者总量守恒。输入值本地持久记忆，但**每次切换股道重算后回到自动值，需重新点校对**才套用。
- **卸车地点（到卸）可配置**：设置面板中可增删「卸车地点」（永鑫 / 货场 / 天盛 / 港务局等）；识别为到卸且记事含这些词时，显示为对应卸车地点并在主表**加粗**。取词规则：多词时按「转」后取末位，否则取首个出现。
- **黑罐识别可配置**：设置面板中可增删「黑罐识别」词（中粮 / 外运等），按**收货人列**识别并在主表加粗。
- **收货人列**：主表明细表新增「收货人」列，置于「车次」列之后。
- **表格列宽记忆**：明细抽屉列宽调整后本地持久化，刷新后保留。
- **设置持久化**：表格字号、默认数据文件夹、显示虚拟股道、卸车地点、黑罐识别等设置均自动持久化到 localStorage。
- **文件切换**：多文件下拉框自动识别最新文件并标记 `● NEW`，文件名格式化为「车数-时间戳」。
- **设置面板**：支持表格字号调节（8px~20px 滑块，带刻度）、默认数据文件夹修改，设置自动持久化到 localStorage。
- **Toast 消息**：右下角消息弹窗，鼠标悬停暂停消失，移开自动关闭。
- **无服务器设计**：方向库与股道配置通过 `<script src>` 加载；xls 通过浏览器 File System Access API 读取，文件夹句柄存入 IndexedDB，实现「打开即自动读取」；不支持的浏览器自动降级为手动选择文件。

## 站存计算（31814）面板说明

点击「功能 → 站存计算」打开弹窗，分左右两栏：

- 左栏：方向筛选、待卸/待装股道分组勾选（按作业区分段，见上「待装股道大组」）。
- 右栏：统计结果表格（车数 / 品名 / 方向 / 各股道存车 等）。

**待卸纠正**（面板底部，与上方大组用分隔线隔开）：

```
C[__] X[__] P[__] G[__]  [待卸校对]
```

- C / X / P / G 为车种输入框（无调节箭头，纯输入）；填入正确车数后点「待卸校对」。
- 套用后：待卸行 = 输入值，空车行按相反偏差增减（G 走分母路罐），总量守恒。
- 切换股道重算后回归自动值，输入框内容保留，需再次点「待卸校对」才重新套用。

## 设置面板说明

「⚙ 设置」面板包含：

- 表格字号调节（8px~20px 滑块，带刻度）。
- 默认数据文件夹修改。
- 显示虚拟股道开关。
- **卸车地点**：到卸识别词列表，可「+」新增、悬停点右上角「×」删除（本地持久化）。
- **黑罐识别**：按收货人列识别的词列表，同上可增删（本地持久化）。

## 使用方式

### VBA 版

1. 用 Excel 打开 `站存计算器-(2026.6.6版).xlsm`（需启用宏）。
2. 按工作簿内说明导入车站现车数据并执行计算。

### HTML 网页版

- **本地直接打开**：双击 `HTML/index.html` 即可（部分浏览器对 `file://` 下读取本地文件有限制，建议使用下方本地服务器方式）。
- **本地服务器（推荐）**：在 `HTML/` 目录下启动任意静态服务器，例如：
  ```bash
  # Python
  cd HTML && python -m http.server 8080
  # 然后浏览器访问 http://localhost:8080
  ```
- **读取数据**：点击「功能 → 设置」选择默认数据文件夹；首次选择后会被记住，之后自动读取。也可通过文件下拉框切换不同数据文件。

## 测试与质量

`aggregate.js` 是纯函数、零 DOM 依赖，回归风险高（规则改错一个分支，站存数字就错且无痕），故配套了 Node 端回归测试：

```bash
node HTML/tests/run.js
```

- 纯 Node 运行，**零依赖、无构建步骤**。
- 覆盖：VBA 函数模拟、carStyle 列索引解耦、方向库解析、到站推断各分支、端到端聚合、股道配置、持久化。
- 已反向验证：将 `aggregate.js` 还原为旧版漏判写法后，测试会精确失败（指向具体记事），证明测试能兜住真实 Bug。
- 修改聚合/到站推断逻辑后，**务必先跑测试再提交**。
