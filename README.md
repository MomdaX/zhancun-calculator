# 站存计算器

铁路车站「股道存车」计算与展示工具，提供 **VBA 版**（Excel 宏工作簿）与 **纯前端 HTML 网页版**（含铁路地图模块）两套实现。

## 在线访问

网页版已部署到 GitHub Pages，点击即可直接使用：

👉 **https://momdax.github.io/zhancun-calculator/index.html**

（根路径 `index.html` 会自动跳转到 `HTML/index.html`。打开后为股道存车计算器，首次需点击「功能 → 设置」选择数据文件夹，或通过「选择文件」按钮加载 xls 现车数据。）

## 功能特性

- **股道存车总览**：按股道展示车数、换长、载重、空/重车、方向、到站、车种、老牌车、到达车次及注意事项。
- **注意事项筛选**：自动从记事列提取「暂不走 / 去向不明 / 点后开 / 列扣 / 检无计划 / 坏 / 超偏 / 未洗 / 禁止 / 有磨损」等简要提示（词级筛选，对齐 VBA 显示逻辑）。
- **注意事项收起 / 展开**：注意事项（第一列）行内右侧提供「收起/展开」矩形按钮，鼠标悬停该列时才浮现；点击整表收起（限高两行并底部淡出）/ 展开正文，状态本地持久化。
- **空线分组开关**：工具栏「隐藏空线分组」一键隐藏组内全部股道均无车的分组（默认开启，按钮文案随状态切换为「显示空线分组」），状态本地持久化。
- **站存计算（31814）**：弹出统计浮窗，按方向/车种/品名等多维度汇总。
- **待装股道大组（作业区）**：31814 面板左栏按「作业区」分组展示股道——
  - 货场作业区（货场）、勒沟作业区（中粮 / 大洋 / 港务局）、鹰岭作业区（永鑫 / 天煤 / 石化 / 国投 / 超智 / 广明 / 天油）、中油作业区（中油）。
  - 单组大组（货场、中油）隐藏子组按钮，计数移到段标题后；**点击段标题可整段全选 / 清空全选**（多组大组同样支持）。
- **待发股道车次芯片**：31814 面板「待发股道」区（到发线 + X 线）逐条悬停出现「＋」，点击输入车次回车后翻转为车次芯片（右上 × 可删），覆盖后该行状态置「待发」，报表「待开」行显示为「股道/车次」；车次映射本地持久化。
- **待卸纠正**：31814 面板底部提供 `C X P G` 输入框与「待卸校对」按钮，对应 VBA「待卸纠正」。自动算出的待卸与实况有偏差时，填入正确车数点「待卸校对」即可：待卸取输入值，空车按相反偏差增减（待卸多了放到空车 / 少了从空车取，G 对应分母路罐），二者总量守恒。输入值本地持久记忆，但**每次切换股道重算后回到自动值，需重新点校对**才套用。
- **生产效率表**：「功能 → 生产效率表」打开浮窗。单表按「夜班 / 白班」两个区段（各 3 台调机）排列「钩数 / 生产时间 / 钩分 / 调机利用率 / 总钩数 / 备注」，下方「合计」区段汇总；任意输入（钩数、生产时间、班次时长等）自动重算，其中生产时间合计以**小时**计；整表内容本地持久化，刷新后保留。表头标题为「钦州港站 \<日期\> 生产效率表」。
- **卸车地点（到卸）可配置**：设置面板中可增删「卸车地点」（永鑫 / 货场 / 天盛 / 港务局等）；识别为到卸且记事含这些词时，显示为对应卸车地点并在主表**加粗**。取词规则：多词时按「转」后取末位，否则取首个出现。
- **黑罐识别可配置**：设置面板中可增删「黑罐识别」词（中粮 / 外运等），按**收货人列**识别并在主表加粗。
- **车型高亮可配置**：设置面板「车型高亮」按车种前缀高亮车种/车号（对齐 VBA 显示信息.bas），可新增车型并配置匹配词 / 启用开关 / 加粗 / 颜色，「恢复默认」回到默认配置（NX/X 平板车等），本地持久化。
- **收货人列**：主表明细表新增「收货人」列，置于「车次」列之后。
- **表格列宽记忆**：明细抽屉列宽调整后本地持久化，刷新后保留。
- **浮窗可拖动**：站存计算 / 设置 / 生产效率表等浮窗均可按住标题栏拖动（按钮、输入框等控件上除外），拖动位置不越出视口。
- **设置持久化**：表格字号、默认数据文件夹、显示虚拟股道、空线分组、卸车地点、黑罐识别、车型高亮等设置均自动持久化到 localStorage。
- **文件切换**：多文件下拉框自动识别最新文件并标记 `● NEW`，文件名格式化为「车数-时间戳」。
- **设置面板**：支持表格字号调节（8px~20px 滑块，带刻度）、默认数据文件夹修改、显示虚拟股道开关，设置自动持久化到 localStorage。
- **Toast 消息**：右下角消息弹窗，鼠标悬停暂停消失，移开自动关闭。
- **无服务器设计**：方向库与股道配置通过 `<script src>` 加载；xls 通过浏览器 File System Access API 读取，文件夹句柄存入 IndexedDB，实现「打开即自动读取」；不支持的浏览器自动降级为手动选择文件。

## 站存计算（31814）面板说明

点击「功能 → 站存计算器」打开浮窗，分左右两栏：

- 左栏：方向筛选、待卸/待装股道分组勾选（按作业区分段，见上「待装股道大组」）、待发股道车次输入（见上「待发股道车次芯片」）。
- 右栏：统计结果表格（车数 / 品名 / 方向 / 各股道存车 / 待开 等）。

**待卸纠正**（面板底部，与上方大组用分隔线隔开）：

```
C[__] X[__] P[__] G[__]  [待卸校对]
```

- C / X / P / G 为车种输入框（无调节箭头，纯输入）；填入正确车数后点「待卸校对」。
- 套用后：待卸行 = 输入值，空车行按相反偏差增减（G 走分母路罐），总量守恒。
- 切换股道重算后回归自动值，输入框内容保留，需再次点「待卸校对」才重新套用。

## 生产效率表说明

点击「功能 → 生产效率表」打开浮窗，标题为「钦州港站 \<日期\> 生产效率表」，结构为**单表**：

- 顶部信息项：日期、安全起始日（默认 2019-03-05）、安全天数（自动推算只读）、夜班 / 白班时长（分钟，默认 夜 780 / 白 660）。
- 正文按「夜班」「白班」两个区段排列，每个区段 3 行（1调 / 2调 / 3调），列含钩数、生产时间、钩分、调机利用率、总钩数、备注。
- 「合计」区段汇总各区段生产时间（**以小时计**）与总钩数。
- 任一行钩数 / 生产时间等变化即自动重算并持久化（localStorage），刷新后保留。

## 使用方式

### VBA 版

1. 用 Excel 打开 `站存计算器-(2026.6.6版).xlsm`（需启用宏）。
2. 按工作簿内说明导入车站现车数据并执行计算。

### HTML 网页版

- **本地直接打开**：双击 `HTML/index.html` 即可（部分浏览器对 `file://` 下读取本地文件有限制，建议使用下方本地服务器方式）。
- **本地服务器（推荐）**：在 `HTML/` 目录下启动任意静态服务器，例如：
  ```bash
  # Python
  cd HTML && python -m http.server 8080
  # 然后浏览器访问 http://localhost:8080
  ```
- **数据同步（推荐）**：双击根目录 `同步并打开.bat`，会从 `C:\Program Files\SIM2.9\TranData` 把最新现车 xls 同步到 `HTML\TranData` 后自动打开主页面（`sync.bat` 仅同步不打开；源目录不存在时自动降级为直接打开页面）。
- **读取数据**：点击「功能 → 设置」选择默认数据文件夹；首次选择后会被记住，之后自动读取。也可通过「选择文件」或文件下拉框切换不同数据文件。

### 接发车作业全流程追踪（离线快照）

`接发车作业全流程追踪/` 目录存放的是「钦州车务段接发车作业全流程追踪」决策系统的**离线另存快照**（帆软 WebReport，含发车/到达作业全流程追踪与查询表单）。该页面需连接原内部报表服务器才能渲染业务数据，**不属于本站纯前端模块**，仅作界面与接入参考。

## 测试与质量

`aggregate.js` 是纯函数、零 DOM 依赖，回归风险高（规则改错一个分支，站存数字就错且无痕），故配套了 Node 端回归测试：

```bash
node HTML/tests/run.js
```

- 纯 Node 运行，**零依赖、无构建步骤**。
- 覆盖：VBA 函数模拟、carStyle 列索引解耦、方向库解析、到站推断各分支、端到端聚合、股道配置、持久化。
- 已反向验证：将 `aggregate.js` 还原为旧版漏判写法后，测试会精确失败（指向具体记事），证明测试能兜住真实 Bug。
- 修改聚合/到站推断逻辑后，**务必先跑测试再提交**。

## 开发与同步

本仓库使用 Git 管理，已托管于 GitHub。本地修改后：

```bash
git add -A

git push origin master
```

> 忽略规则（`.gitignore`）：Excel 临时锁文件（`~$*`）、本地配置（`workbook-path.json`）、IDE/调试目录（`.trae/` `.workbuddy/` `_diag/`）、`node_modules/` 及本地样本数据目录 `xlsdata/` 不入版本库。注意：VBA 主工作簿（`.xlsm`）与同步数据 `HTML/TranData/` 目前**纳入版本控制**，若某次同步产生体积过大的 xls 需留意。

### app.js 结构提示

`app.js`（约 1500 行）未做文件拆分，`state` 为 IIFE 内私有对象。文件顶部注释含**功能区块索引**（列定义 / 数据源 / 主表渲染 / 明细抽屉 / 明细多选 / 事件绑定 / 入口）及对应行号，定位功能时先查该索引。如需拆分，数据源区块（`ensurePerm`/`pickFolder`/`loadFromDir` 等）耦合最弱、最优先。
